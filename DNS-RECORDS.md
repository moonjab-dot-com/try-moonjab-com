# DNS Records for moonjab.com

Add these records in your DNS provider (Namecheap, Cloudflare, GoDaddy, etc.).
Last reviewed: 2026-05-14

---

## SPF Record — Sender Policy Framework

Tells receiving mail servers which servers are authorized to send email for moonjab.com.
Prevents spammers from forging the `From: @moonjab.com` header.

| Type | Host | Value | TTL |
|------|------|-------|-----|
| TXT | @ | `v=spf1 include:_spf.google.com ~all` | 3600 |

> **`~all`** = soft fail (recommended while testing). Once confirmed working, upgrade to **`-all`** (hard fail).
> If you send email from services other than Google Workspace, add their include:
> - SendGrid: `include:sendgrid.net`
> - Mailchimp: `include:servers.mcsv.net`
> - Vercel (no email sending, no include needed)

**Full record if using only Google Workspace:**
```
v=spf1 include:_spf.google.com ~all
```

## DMARC Record — Domain-based Message Authentication, Reporting & Conformance

Tells receiving servers what to do when SPF/DKIM checks fail, and where to send reports.

| Type | Host | Value | TTL |
|------|------|-------|-----|
| TXT | _dmarc | `v=DMARC1; p=none; rua=mailto:dmarc@moonjab.com; ruf=mailto:dmarc@moonjab.com; fo=1; adkim=r; aspf=r` | 3600 |

**Breakdown:**
- `p=none` — monitor only, no enforcement (start here)
- `rua=mailto:dmarc@moonjab.com` — aggregate reports (daily digest)
- `ruf=mailto:dmarc@moonjab.com` — forensic reports (per-failure)
- `fo=1` — generate forensic report on any failure
- `adkim=r` — relaxed DKIM alignment
- `aspf=r` — relaxed SPF alignment

### Upgrade path (recommended rollout):

1. **Week 1–2:** `p=none` — collect reports, verify legitimate mail passes
2. **Week 3–4:** `p=quarantine; pct=10` — quarantine 10% of failing mail
3. **Month 2:** `p=quarantine; pct=100` — quarantine all failing mail
4. **Month 3+:** `p=reject` — reject all failing mail (full enforcement)

**Final production record:**
```
v=DMARC1; p=reject; rua=mailto:dmarc@moonjab.com; ruf=mailto:dmarc@moonjab.com; fo=1; adkim=r; aspf=r
```

## DKIM

DKIM signing keys are generated by your email provider and added automatically when you verify your domain:
- **Google Workspace:** Admin Console → Apps → Google Workspace → Gmail → Authenticate email → Generate DKIM
- The DKIM TXT record name will be something like: `google._domainkey` at `moonjab.com`
