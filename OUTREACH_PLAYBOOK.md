# MoonJab — Playbook de Backlinks y PR

Objetivo: conseguir backlinks de calidad (DA 40+) de sitios relevantes en LATAM para escalar el Domain Authority de moonjab.com desde 0 hasta un nivel competitivo.

---

## Por qué backlinks primero

El technical SEO ya está al 100%. Lo que frena el ranking es la autoridad de dominio. Un solo backlink de una universidad (.edu) o de un medio tech LATAM (DA 60+) vale más que 50 artículos de blog propios para mover el needle en Google.

**Prioridad de tipos de backlink:**
1. `.edu` — universidades (DA 50–85, máxima autoridad para Google)
2. Medios tech/startup LATAM (DA 55–80)
3. Blogs de RRHH/carrera en español (DA 30–60)
4. Directorios de herramientas (DA 40–70)
5. Comunidades/foros (DA 70+ pero nofollow, igual genera tráfico)

---

**Pitch:** No pidas que escriban sobre ti. Pide que te incluyan en su sección de "herramientas para estudiantes" o "recursos de empleabilidad". Es una cosa pequeña para ellos, enorme para ti.

## Bloque 5: Comunidades (nofollow pero tráfico real)

No generan backlinks follow, pero generan tráfico referido y menciones que Google lee como señales de marca.

### Reddit

Participar genuinamente en:
- **r/colombia** — "Cómo hacer CV para conseguir trabajo en Colombia"
- **r/mexico** — "Herramientas para buscar trabajo en México"

## Bloque 6: Mención en "listas de recursos"

Buscar artículos ya publicados que listan herramientas de carrera/CV y pedir que te añadan (broken link building + resource page link building).

### Búsquedas para encontrar targets

En Google busca:
- `mejores herramientas para hacer cv site:*.edu`
- `herramientas gratis hacer currículum latam`
- `recursos para estudiantes empleabilidad`
- `"crear cv" "herramientas" "gratis" latam`

Cuando encuentres una lista que no te menciona, escribe al autor/webmaster:

```
Asunto: Sugerencia para tu artículo "Las mejores herramientas para hacer CV"

¿Lo considerarías para una actualización del artículo?

[Tu nombre]
```
